# AUTOSEMI

Automaticly insert **semicolon** after some kinds of lexemes
if they are at the end of the line.

# ALTKEYWORDS

Allow using keywords **not**, **and**, **or**, **then**, **else**
instead of **!**, **&&**, **||**, **?**, **:**.

# LOOPELSE (todo)

Allow **else** statement after **do**, **while**, **for** and **switch**.

# NANBOXING

Use NaN-boxing technique.

# SWITCHEDGOTO

Use [switched goto](https://bullno1.com/blog/switched-goto) technique.

# DEBUG

Print debug information and use asserts.
